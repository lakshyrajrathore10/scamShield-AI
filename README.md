ScamShield AI is an intelligent real-time scam and threat detection platform built with React, Tailwind CSS, and Vite.

## 🚀 Features

- **Multi-Vector Threat Scanner**: Analyze suspicious SMS, emails, phishing URLs, UPI fraud identifiers, and crypto scams.
- **Explainable AI Risk Scoring**: Clear risk breakdown with threat level indicators (Safe, Suspicious, Dangerous).
- **Heuristic & Pattern Detection**: Detects spoofed domains, urgent psychological triggers, deceptive payment links, and suspicious APK downloads.
- **Privacy First**: Fast client-side heuristics & analysis.

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS v4
- **Icons**: Lucide React

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/lakshyrajrathore10/scamShield-AI.git
cd scamShield-AI
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
